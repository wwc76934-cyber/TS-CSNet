# TS-CSNet 中期汇报 PPT 设计规范 (`design_spec.md`)

> 参考 `hugohe3/ppt-master` 的 Spec-First（先锁规范再生成）与绝对坐标网格设计原则，确保全套 14 页 PPT 兼具**北大金融学术简约美感、视觉节奏一致性与 PowerPoint/WPS 100% 原生可编辑性**。

## 1. 画布与网格契约
- **画布尺寸**：16:9 宽屏（`13.333 × 7.500 in`，逻辑坐标 `1280 × 720 px`，`1 px = 9525 EMU`）
- **页边距**：左 `56 px`、右 `56 px`（内容安全宽度 `1168 px`）、顶区 `0..86 px`、底栏 `686..712 px`
- **固定页眉区（`y = 18..86`）**：
  - 顶部左侧：章节点位 Kicker（`10.5pt Bold`, PKU Crimson `#8B1A24`）
  - 主标题：结论导向的一句话标题（`22pt Bold`, Institutional Navy `#1B365D`）
  - 分割细线：`y = 84`，左段 `140 px` 深红 `#8B1A24` + 右段浅灰 `#E2E8F0`
- **固定页脚区（`y = 688..710`）**：左侧项目简称（`8.5pt`, `#64748B`），右侧页码 `XX / 14`

## 2. 北大学术简约配色体系
- **主品牌强调色（PKU Crimson）**：`#8B1A24`（顶部细条、章节标识、关键结论框）
- **数据与标题主色（Institutional Navy）**：`#1B365D`（标题、表头、主数据卡）
- **辅助蓝色（Steel Blue）**：`#2B5B84`
- **正向语义色（Forest Emerald）**：`#1B6B4F`（正超额、超配、优势环境）
- **警示/负向色（Brick Red）**：`#B91C1C`（回撤、排雷清零、失效边界）
- **中性底色**：纯白画布 `#FFFFFF`、卡片浅底 `#F5F7FA`、警示浅底 `#FDF5F6`、正向浅底 `#F2F9F6`、边框线 `#CBD5E1`、正文深灰 `#1E293B`、次级文字 `#475569`
